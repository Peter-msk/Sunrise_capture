# Sunrise Capture

Sunrise Group의 Windows 화면 캡처·녹화·이미지 편집 프로그램입니다.

## 프로그램 목적

업무 화면, 오류 상황, 문서 작업 과정 등을 이미지와 동영상으로 기록하고 편집해 보고서, 매뉴얼, 검토 자료를 효율적으로 제작합니다.

## 지원 운영체제

- Windows 10 / Windows 11 (64비트, x64)

## 개발언어 및 주요 기술

- **개발언어:** Python
- **주요 기술:** PySide6(Qt) 기반 데스크톱 UI, Windows 화면 캡처·녹화 처리
- **배포 형태:** Windows 설치형 프로그램

## 주요 기능

- 전체 화면, 활성 창, 지정 영역, 반복 영역 및 모니터별 화면 캡처
- 다중 영역·스크롤 캡처와 JPG 이미지 저장
- 동일 영역의 변경 전·후 화면 비교 및 차이 표시
- 지정 영역 MP4 화면 녹화, 화질 설정, 일시정지·재개
- 펜, 화살표, 도형, 텍스트, 형광펜 및 모자이크 편집
- 이미지 저장, 클립보드 복사, 최근 결과 확인 및 작업 복구
