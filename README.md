# Sunrise Capture

> 업무 화면을 빠르게 캡처하고, 필요한 부분을 편집·저장·공유할 수 있도록 설계한 Windows 화면 캡처 및 영역 녹화 도구

## 1. 프로그램 소개

Sunrise Capture는 보고서 작성, 오류 기록, 업무 매뉴얼 제작, 현장 자료 정리, 프로그램 검토와 같은 실무 과정에서 화면 정보를 빠르고 정확하게 남기기 위한 프로그램입니다.

단순히 화면 한 장을 저장하는 기능에 머무르지 않고, 캡처 범위 선택, 반복 캡처, 즉시 JPG 저장, 다중 영역 캡처, 스크롤 캡처, 영역 녹화, 편집, 클립보드 연동, 최근 항목 관리까지 하나의 작업 흐름으로 연결하는 것을 목표로 합니다.

각 캡처 방식은 서로 독립된 워크플로로 구성되어 있어, 사용자는 현재 필요한 기능만 선택하여 복잡한 설정 없이 작업할 수 있습니다.

## 2. 개발 목적

Sunrise Capture의 핵심 목적은 다음과 같습니다.

1. 업무 화면을 최소한의 조작으로 정확히 기록합니다.
2. 캡처 직후 필요한 표시와 보정을 수행하고 결과를 즉시 활용할 수 있게 합니다.
3. 여러 모니터와 다양한 Windows 화면 배율에서도 안정적으로 동작하도록 합니다.
4. 녹화와 캡처를 명확히 구분하여 사용자가 현재 수행 중인 작업을 쉽게 인지하도록 합니다.
5. 백그라운드 감시나 자동 업로드 없이 사용자 조작 기반으로만 동작하는 안전한 캡처 도구를 제공합니다.

## 3. 주요 기능

### 화면 캡처

- 사용자가 직접 드래그하여 범위를 지정하는 영역 캡처
- 지정한 영역을 유지하면서 여러 번 반복하는 영역 지정 후 캡처
- 별도 편집 단계 없이 지정 폴더에 저장하는 JPG 바로 저장
- 여러 개의 범위를 각각 지정하여 처리하는 다중 영역 캡처
- 긴 웹페이지나 문서 화면을 이어서 저장하는 스크롤 캡처
- 현재 모니터 전체를 저장하는 전체 화면 캡처
- 현재 활성화된 프로그램 창을 저장하는 활성 창 캡처
- 다중 모니터 환경에서 사용할 화면을 고르는 모니터 선택

### 영역 녹화

- 사용자가 지정한 화면 영역 녹화
- 녹화 품질 단계 선택
- 마지막으로 사용한 녹화 품질 기억
- 캡처 영역과 실행 도구막대를 분리하여 좁은 영역에서도 제어 버튼이 사라지지 않는 구조
- 녹화 중지와 완료 상태를 사용자가 명확하게 확인할 수 있는 흐름

### 이미지 편집과 클립보드

- 캡처 결과에 선, 사각형, 원·타원, 화살표, 텍스트, 형광펜, 모자이크 등의 표시 적용
- 편집 색상과 선 굵기 설정 기억
- 편집 결과를 현재 플로우 화면, 저장 파일, 클립보드에 동일하게 반영
- 저장 후 편집 결과 창을 자동으로 닫지 않고 사용자가 계속 확인하거나 추가 작업 가능
- 지정 경로 저장과 다른 이름으로 저장 지원

### 작업 관리

- 최근 캡처 결과 확인
- 저장 폴더와 마지막 저장 시각 표시
- 결과 폴더 바로 열기
- 사용자 설명서, 로그 폴더, 진단 정보 저장 기능 제공
- 공지사항과 업데이트 정보 확인

## 4. 기본 사용 흐름

```text
캡처 방식 선택
→ 화면 또는 영역 지정
→ 캡처·저장·녹화 실행
→ 필요한 경우 이미지 편집
→ 지정 폴더 저장 또는 다른 이름으로 저장
→ 클립보드 붙여넣기·최근 항목·결과 폴더에서 활용
```

## 5. 설계 방향

Sunrise Capture는 기능이 많은 프로그램보다, 캡처 순간에 방해가 적고 결과가 예측 가능한 프로그램을 지향합니다.

- 캡처, JPG 저장, 녹화, 다중 영역 작업을 서로 혼합하지 않습니다.
- 좁은 영역에서도 선택 프레임과 작업 도구가 겹치거나 사라지지 않도록 합니다.
- 100%, 125%, 150% Windows 화면 배율과 다중 모니터 환경을 지속적으로 검증합니다.
- 편집 결과와 저장 결과, 클립보드 결과가 서로 달라지는 문제를 방지합니다.
- 저장 위치와 현재 상태를 항상 사용자가 확인할 수 있게 합니다.
- 사용자가 조작하지 않은 백그라운드 캡처, 자동 업로드, 상시 화면 감시는 포함하지 않습니다.

## 6. 향후 개발 방향

- 스크롤 캡처의 브라우저·문서 프로그램별 호환성 강화
- 고해상도·고배율·다중 모니터 좌표 처리 안정화
- 장시간 영역 녹화의 메모리 사용량과 파일 안정성 개선
- 편집 도구의 정밀도와 실행 취소·재작업 흐름 강화
- 업무 유형별 캡처 프리셋과 파일명 규칙 제공
- 최근 항목 검색, 분류, 빠른 재편집 기능 강화
- 캡처와 저장 과정의 성능 측정 및 장애 진단 정보 개선
- 설치·업데이트 과정의 단순화와 공식 서명 배포 체계 유지

## 7. 지원 환경과 배포

- 대상 운영체제: Windows 10/11 64비트
- 기본 배포 형태: 설치형 Setup EXE
- 현재 공개 README 작성 기준: Sunrise Capture v3.8.0
- 공식 업데이트는 사용자의 승인 후 다운로드와 무결성 확인을 거쳐 진행하는 방향을 따릅니다.

## 프로젝트 공통 원칙

Sunrise Group의 프로그램은 단순한 일회성 스크립트가 아니라 실제 업무에서 반복 사용할 수 있는 Windows 데스크톱 도구를 목표로 합니다.

- 원본 파일과 사용자 데이터를 우선적으로 보호합니다.
- 삭제, 다운로드, 업데이트, 외부 프로그램 실행 등 중요한 동작은 사용자가 인지하고 승인한 경우에만 수행합니다.
- 사용자 문서, 이미지, 프로젝트 데이터와 API 키를 불필요하게 외부로 전송하지 않습니다.
- 장시간 작업은 진행 상태와 현재 처리 단계를 표시하고, 오류 발생 시 사용자용 안내와 진단 로그를 분리합니다.
- 공식 배포본은 제품 정보, SHA-256 무결성 확인, 코드 서명, AhnLab/V3 사전점검 등 Sunrise Group의 배포 기준을 따릅니다.
- 기능 추가보다 기존 기능의 재현성, 복구 가능성, 대용량 처리 안정성, 유지보수성을 우선합니다.
